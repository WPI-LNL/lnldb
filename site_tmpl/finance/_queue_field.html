Writing that out per field is what produced four near-identical twelve-line blocks that drifted apart, so it lives here once and each row is a single include. There used to be an `options` parameter that rendered a whole row of chips under the event picker -- five scored guesses at which show a deposit belonged to. Guessing was the wrong shape for that field: the ISD memo names the event outright, so it is a lookup that fills the box in, and five candidates under a box is a puzzle rather than a shortcut. {% endcomment %}
