{# One field of a queue row, with a caption saying where its answer came from. #} {% comment %} One control on a reconciliation row. Every field on the queue is the same three things stacked: a label, the widget, and at most one caption underneath saying where the answer came from. Writing that out per field is what produced four near-identical twelve-line blocks that drifted apart, so it lives here once and each row is a single include. Parameters: field a bound form field (required) label the visible label (required) size sm | md | lg -- fixes the control width so the same field lines up vertically down the page, which is how the queue is read autofilled the Suggestion the form already applied, if any suggestion a Suggestion to offer as a clickable chip, used only when nothing was auto-filled: a box that is already answered should not also be nagging At most one caption, always, and a filled box always carries one. The caption is not decoration: it is what stops an autofilled answer from reading as an authority it does not have. A category taken off a funding request line and a category guessed from a fund's default are both pre-selected, and the row says which is which -- ``Suggestion.source`` is the word it says it with. See the module docstring of ``finance/suggestions.py``. There used to be an `options` parameter that rendered a whole row of chips under the event picker -- five scored guesses at which show a deposit belonged to. Guessing was the wrong shape for that field: the ISD memo names the event outright, so it is a lookup that fills the box in, and five candidates under a box is a puzzle rather than a shortcut. {% endcomment %}
