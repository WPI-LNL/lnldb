Money going out, and any balance below zero, is in (parentheses). Each fund's row adds up across: Opening + Came in + Spent + Transfers = {% if year.year_over %}Closing{% else %}Now{% endif %}.

$0 is nothing, ? is not known yet, and — means the figure does not apply to that row.

How to read this page
  • After encumbrances is {% if year.year_over %}Closing{% else %}Now{% endif %} + Encumbered: what is left once the purchases logged in advance are charged. For a fund SGA reimburses it is below zero by what SGA will owe.
  • Event costs awaiting payment: an expense linked to an event is not taken from Legacy (or any fund that carries forward) until the event is paid for. Until then it waits in a row of its own, and moves into the fund under Transfers on the day the event's bill is marked paid.
  • Billed, not paid: what billed events still owe. It is not cash until it arrives, so it is shown beside the fund it will land in, not counted in it.
  • Not settled yet: lines still in the queue. With them, the funds add up to the account's cash.
  • Balances count every settled line, whichever Projection or Event Production side it was for.
